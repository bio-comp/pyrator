# Bibliography Guidelines

This directory contains bibliographic references for the Pyrator project.

## File Structure

- `references.bib` - Main BibTeX file containing all citations
- PDF files should be stored in `../papers/` using the naming convention: `{arxiv-id}.pdf` or `{doi}.pdf`

## Adding New References

1. Add the BibTeX entry to `references.bib`
2. Follow standard BibTeX formatting
3. Include DOI or arXiv ID when available
4. Use descriptive citation keys (e.g., `author2024keyword`)

## Categories of References

- **Inter-rater Agreement Metrics**: Cohen's Kappa, Fleiss' Kappa, Krippendorff's Alpha
- **Statistical Methods**: ICC, Bayesian approaches
- **Data Annotation**: Quality estimation, active learning
- **Applications**: NLP, medical imaging, social sciences

## Citation Key Convention

Format: `{first-author}{year}{keyword}`
Example: `klie2024efficientstatisticalqualityestimation`
